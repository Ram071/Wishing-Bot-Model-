Wishing Bot Model 🎉
About the Project

Wishing Bot Model is a fun and interactive Python application that lets you send greetings in a creative coding style.

🎉 Creates colorful and dynamic emoji animations to make greetings more attractive.

🎵 Plays a background song while the greeting is being displayed.

📂 Automatically detects all songs available in the Wishing_Bot_Model directory.

🎶 Displays the available songs and allows you to choose one for your occasion.

➕ Add as many songs as you want to expand the collection.

🚀 Customize the project and add new features to make your Wishing Bot more engaging.

Tech Stack
Python Modules Used

pygame – Plays the selected background music.

threading – Runs the music and emoji animation simultaneously.

random – Generates random positions for the emojis.

sys – Handles system-level operations.

os – Manages files and directories.

time – Controls timing and animation speed.

Requirements

Python 3 or later

Pygame

Install Pygame using:

pip install pygame


After installing the required dependencies, run the program and enjoy creating personalized wishes with music and emojis! 🎊
